# 启动器的存档目录与数据状态

原先无参数启动的窗口显示服务地址和账号选择。用户难以区分正在查看的存档，也无法从窗口判断游戏表是否已经加载。已有的显式命令行选项可以指定数据目录，资源管理器把文件夹拖到程序上时则传入单独的绝对路径，旧版会将它当成未知子命令。

启动窗口现提供可选中复制的完整存档路径和当前配置名。服务成功初始化后显示存档库已打开，游戏表加载完成时显示实际表数和指纹前缀，缺表时给出文字提示。信息来自已启动的服务。停止时清除就绪状态。

Windows EXE 支持把含 `settings.json` 或 `terralocal.sqlite3` 的存档文件夹拖到程序上。它使用与无参数启动相同的窗口入口和原有设置校验。拖入无关目录会提示所需的存档文件，原目录不会被初始化。

20 项相关检查通过，覆盖两种存档标记、含中文和空格的路径、默认目录隔离、无关目录保护，以及已有启动和诊断路径。证据在 `.cache/portable-launcher-20261118/tests.xml`。
