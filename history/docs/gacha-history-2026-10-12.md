# 寻访记录原版网页接入与验收

A12 的历史复现为原生“查询记录”请求 `/gacha?pool_id=…` 返回 501。本轮已接入原版网页资源和持久化记录查询，并通过新 EXE 的实际 TLS、原生页面与重启验证。A12 按此范围修复；整个寻访系统及私服仍未达到成熟交付要求。

## 资源与协议

冻结网页版本 `cn-2.7.71-20261012` 对应 CN Android 2.7.71 / 190、原始 APK SHA `0b79b85383e21a6343283bc6bfd7a9d24eb4134abf901115f757da6a5d50f6db`、资源 `26-09-22-07-47-20_6c71fa`。只接受当前兼容配置和 GameData 绑定的相同基线。

原始 HTML、脚本和样式从公开网页取得；完整本地清单为 HTML 加 83 个静态资源，共 6,108,538 服务字节。四个可视脚本保持原字节，两个 CSS 只改资源路径，HTML 保留原 DOM、视口与加载顺序，仅移除遥测并改本地资源路径。清单 SHA `044b7b93f8a6d3bbce9926dde3a3e9f8bbfa6caa663fd644a941a354aa3a301a` 固定在加载器，服务中没有资源下载分支。

资源放在本地 `data/client/webview/cn-2.7.71-20261012`，不进入 Git 或服务器发行物。加载器检查版本、路径、媒体类型、大小、SHA 和资源完整性；缺失、损坏或错版本显式失败，不能用临时自制页面掩盖。此前自制页面仅用于验证认证桥，已从生产代码移除。

原版脚本请求 `/api/gacha/cate` 和 `/api/gacha/history`，严格接受有效本地 U8 会话。记录来自持久化 `gacha_history`，按账号、卡池类型和游标过滤，排除公开招募；保存的稀有度和首次获得标记不重算。时间与位置共同分页，避免十连同秒记录遗漏。

按原版页面“可查询90日内寻访记录”文案采用滚动 90 天显示窗口，旧记录保留在存档；官服精确日界截点尚未取得认证后依据。时间倒退不删除历史。坏记录单独拒绝，不能被窗口过滤伪装成空成功。分组 ID 和位置仍为本地兼容选择，详见 REA 报告。

认证查询参数不进入日志、错误、HTML 或远程遥测。原版动态样式需 `style-src 'unsafe-inline'`，脚本仍仅允许同源，字体/连接只额外允许客户端的 `http://127.0.0.1:51596`；没有开放外部 CDN 或官方认证主机。

## 实际原生观察

在新的独立源码副本上，通过游戏主页→寻访→查看详情→查询记录打开原版界面。SDKv2 和原始 Java WebView 桥保持，index 0 原实例未运行。原版背景、布局、分组标签、稀有度颜色、NEW 效果与翻页按钮实际显示。

- 标准 32 条记录：四页分别 10、10、10、2 条，第四页下一页禁用。
- 中坚 11 条记录：两页分别 10、1 条，第二页下一页禁用。
- 客户端本机字体服务实际返回两套 TTF，HTTP 200。Sans 为 10,294,232 字节，SHA `f09e7abc149f1079ea73ab8dffd31d4f5f9dc30c1d7716d4770f87d84be3b6c9`；Serif 为 13,626,252 字节，SHA `8f589e65ce57c78e10d191fc13ece16e5a5d688f52aaa097527038383b6264a6`。sfnt 签名与 Unicode 字体名称分别匹配 Source Han Sans/Serif CN Medium。临时 ADB 字体端口转发已移除。
- 已观察流程的 188 次服务器请求全部 200；九张玩法表、42 干员/43 抽、119 份受保护输入保持，数据库完整性 ok。

冷启动初期有一次黑屏和一次 ADB 身份校验超时，随后主页与登录/同步正常；没有把它当作网页成功。源码会话于预设 30 分钟上限结束，尚未执行限定空分组、关闭返回、重启恢复。会话大部分时间用于检查，不能计为两小时连续游玩。

这次原生源码观察发生在增加 90 天窗口之前；网页字节与接口字段相同，但新的领域规则仍需最新测试和新 EXE 验证。完整脚本、每一步截图、字体校验、路由统计与状态指纹保留在本地忽略的 `.cache/gacha-history-official-2026-10-12`。
