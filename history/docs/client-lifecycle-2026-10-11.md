# 启动器连接生命周期修复与验收（2026-10-11）

**A02 的已冻结客户端连接流程已修复并验证。** 源服务和实际 Windows EXE 均能自动启动已绑定测试实例、替换到期的有限期 SDK 凭据、恢复冷启动路由并完成真实游戏登录。有效凭据在服务器重启后复用，健康轮询不重复签发。此结论不表示主要玩法、完整启动窗口或成熟发行验收已完成。

## 实现与使用范围

启动窗口增加本地账号选择、连接、重新连接和取消自动连接。服务就绪后启动独立后台任务，按账号 ID 与私密 UID、测试实例、APK、资源、兼容配置和 GameData 绑定；没有绑定时不操作模拟器。切换账号明确重新打开游戏，取消连接停止后续维护，已经建立的游戏会话仍按正常期限失效。

SDK 凭据由受信任的桌面任务生成，数据库只保存散列，客户端回调文件保存在所用存档目录的 `launcher-client` 中。默认有效期仍为 24 小时；在到期前更新有限期文件，已过期凭据仍返回 401。没有增加可通过网络绕过认证阶段的接口。正常轮询、文件内容修复和进程重启均复用有效凭据。

Windows 文件采用临时写入、fsync 和原子替换；Android 端先推送临时文件，再校验和重命名。文件被占用时取消操作保持待处理，不会在下一轮意外恢复连接。停止请求取消后台命令；任务退出前不会关闭其仍使用的数据库。ADB 命令有超时，后台启动和退出不阻塞 Tk 主事件循环。

连接适配只接受 index 1 / TerraLocal / 已冻结安装记录，并校验 Android 设备标识、APK SHA-256、资源索引、真实 GameData 和兼容配置。进程级命名互斥量防止多个存档同时控制同一实例；每条特权命令再次检查设备标识。未知 APK、绑定账号变更、不同设备、冲突挂载或证书会明确报错。

目标基线是国服官服 Android 2.7.71 / 190，资源 `26-09-22-07-47-20_6c71fa`，SDK v2 适配 APK SHA-256 `f75a9643d2d3fb487e5da082492cb2336bce399cabdc0725a895efd186df2e01`；兼容配置 `cn-android-2.7.71-display`，18 表 GameData 指纹 `f44199a7d34a82bdbb232674db3a3cdf9d7958230217fce3960ccafd351b7406`。当前实现不自动适配其他版本或未准备的实例。

冷启动恢复检查 ADB reverse、七个配置域名的 hosts 覆盖、CA 可见指纹、仅游戏应用 UID 的 443 转发以及 IPv4/IPv6 外网拒绝规则。先建立应用外网保护，再恢复本地覆盖；拒绝接管未知绑定挂载。原 index 0 和原正式存档保持。本轮没有使用旧 `connect_test_instance.py`。

生产变更为四个连接模块和 `service.py`、`window.py`，新增三个测试文件。来源及指纹见 [source-inventory.json](../.cache/client-lifecycle-2026-10-11/source-inventory.json)，SHA-256 `5b0fa534a74ae9928a9bce2bfc2e463cabdd503aec72ffe24c9daeab04a6fa8c`。范围包含 87 个生产文件、27 个工具文件、46 个测试文件；相对前次清单为 2 个变更、7 个新增、0 个删除。
